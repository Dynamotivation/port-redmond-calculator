# Selawik 1.01

These are the unmodified TrueType binaries from Microsoft's Selawik 1.01
release:

https://github.com/microsoft/Selawik/releases/tag/1.01

Selawik is Microsoft's open-source replacement for Segoe UI. The font is
licensed separately from this repository's application code under the SIL Open
Font License 1.1. See `LICENSE.txt`. The reserved font name is `Selawik`.

Bundled files map to the Regular, Bold, Light, Semibold, and Semilight faces
published in Microsoft's `Selawik_Release.zip` archive.
