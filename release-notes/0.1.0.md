- First public release of Redmond Calculator, a cross-platform Fluent-style calculator that reuses the Microsoft Calculator engine.
- Standard, scientific, programmer, date calculation, unit conversion and graphing modes, with calculation history.
- Optional currency conversion from a source you choose; nothing is contacted before you agree, and amounts are always calculated on your device.
- The Settings page lists every open source component and its license, including Microsoft Calculator.
- Installs for the current user on Windows 10 (version 1607) or newer, 64-bit, with a signed setup.
